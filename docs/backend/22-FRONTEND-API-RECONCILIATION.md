## Route limitations

- `GET /health/ready`: 503 and {ready:false} when required dependencies fail.
- `POST /api/v1/projects/:projectId/snapshots`: Requires a native-authorized Git root. 202 result is polled through operations. Snapshot artifact is quarantined; knowledge indexing is deferred.
- `POST /api/v1/artifacts/:artifactId/export`: Exact destinationRef must be registered by native owner command. No overwrite. Replay never dispatches again; blocked/uncertain effects require reconciliation.
- `GET /api/v1/projects/:projectId/artifacts`: Only limit/cursor are supported. Owner-approved clarification reserves kind until a taxonomy is approved and defers runId to Stage 07 ownership; both are strictly rejected now.
- `GET /api/v1/settings`: Privacy/limits project active policy; conflicting PATCH returns 409. Retention/defaultAutonomy are preferences, not purge or execution authorization.
- `PATCH /api/v1/settings`: Privacy/limits project active policy; conflicting PATCH returns 409. Retention/defaultAutonomy are preferences, not purge or execution authorization.
- `PATCH /api/v1/settings`: Owner session only; no extra human-presence provider is currently configured.
- `POST /api/v1/policies/revisions`: Owner session only; no extra human-presence provider is currently configured.
- `POST /api/v1/policies/:revisionId/activate`: Owner session only; no extra human-presence provider is currently configured.

## Compatibility and exclusions

Canonical health is `/health/live` and `/health/ready`. `/api/v1/health/*` is compatibility-only and retains its older diagnostic DTO. Cookie name is imported from the implementation: `asi_local_session`.

- Legacy /api/ui/v1 routes are a separate adapter, not automatic canonical aliases.
- Frontend /api/chat is separate pre-existing UI code, not a governed Stage 06 generation API.
- Stages 07–18, including goal inference, runs/SSE, memory and deployment, are not exposed by this manifest.

Stage 02 exposes no database API. No arbitrary SQL, host path, credential retrieval, shell, or direct generation endpoint is added.
