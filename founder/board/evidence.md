# Primary-source check

Checked 2026-10-21. Documentation establishes advertised capability, not quality, adoption, retention, or willingness to pay. This is a limited overlap check, not an exhaustive competitor map.

- [Codex app introduction](https://openai.com/index/introducing-the-codex-app/): graphical management of parallel agents, isolated worktrees, skills, automations, and continuity with CLI history/configuration.
- [Claude Code desktop documentation](https://code.claude.com/docs/en/desktop): parallel sessions, worktree isolation, and graphical review of changes.
- [Hermes official repository](https://github.com/NousResearch/hermes-agent): provider choice, local terminal execution, persistent memory documentation, tools, and isolated subagents; README also describes Desktop subagent provider/model settings.
- [OpenClaw Control UI](https://docs.openclaw.ai/web/control-ui): browser UI served by its gateway, agent status, sessions, and live tool progress.

Chair's inference: graphical agent management, local execution, and provider flexibility cannot be presumed unique. Sources do not establish that any product fully solves the founder's intended workflow, nor that buyers would pay for an alternative. Do not infer inferior competitor UX without direct comparative testing.
